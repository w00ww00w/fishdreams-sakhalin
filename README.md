# Рыба моей мечты и Рыбку съесть

Адаптивный сайт ресторана для GitHub Pages: семь страниц, меню, барная карта, кафе, доставка, контакты и бронирование через WhatsApp. Изображения и шрифты находятся в репозитории. Сервер, база данных и платные сервисы для работы сайта не нужны.

Сайт суши-бара «Рыбку съесть» расположен по адресу `rybku-syest/`: главная, меню и контакты. Оба сайта связаны переключателем заведений и ссылками на главных страницах.

## Публикация

1. Загрузите содержимое этого каталога в ветку `main` публичного репозитория `fishdreams-sakhalin`.
2. В настройках репозитория откройте **Settings → Pages → Build and deployment** и выберите **Source: GitHub Actions**.
3. В **Actions** запустите **Publish restaurant website**. Следующие изменения в `main` будут публиковаться автоматически.

Адрес сайта покажется в результате задания `deploy` и в Settings → Pages. Он будет доступен посетителям без входа в аккаунт.

## Редактирование

- `site/index.html` — главная страница.
- `site/menu/index.html` — полное меню ресторана.
- `site/bar/index.html` — барная карта.
- `site/about/`, `site/cafe/`, `site/delivery/`, `site/contacts/` — остальные страницы.
- `site/rybku-syest/` — сайт суши-бара: главная, меню, контакты, оформление и изображения.
- `site/shared/chrome.css` и `site/shared/chrome.js` — общее оформление шапок, подвалов и поведение навигации обоих заведений.
- `site/styles.css` — оформление, `site/app.js` — взаимодействия и анимации.
- `site/assets/` и `site/fonts/` — изображения и шрифты.

В исходных файлах `site/` используйте пути от корня, например `/assets/image.jpg`. При публикации скрипт `tools/prepare_pages.py` автоматически добавит путь репозитория к ссылкам, изображениям и шрифтам, а также обновит canonical, Open Graph, sitemap и robots.txt. При подключении своего домена тот же скрипт использует его адрес.

Подготовка вручную, без дополнительных зависимостей:

```sh
python3 tools/prepare_pages.py --base-url https://YOUR-ACCOUNT.github.io/fishdreams-sakhalin
```

Результат появится в `_site/`.

Контент и материалы бренда перенесены с fishsakhalin.ru. Запрос бронирования открывает WhatsApp; подтверждение выполняет ресторан. Автоматической оплаты и подтверждения брони нет.

Материалы суши-бара: rybku-syest.clients.site и публичный канал t.me/rybku_syest. В меню суши-бара 14 позиций, 12 опубликованных цен. Для двух блюд цена уточняется у команды. Бронирование суши-бара выполняется по телефону, указанному на сайте.
